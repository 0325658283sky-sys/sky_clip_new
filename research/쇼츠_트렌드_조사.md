## 2. 국내 쇼츠에서 흔한 레이아웃: "3단 구성"
- **상단 제목 / 가운데 16:9 원본 영상 / 하단 자막** 구성이 국내 외주 편집 서비스에서 실제로 쓰인다. 얼굴 추적 크롭 없이 원본 화면을 그대로 살린다.
- 16:9 파일을 그대로 올리면 쇼츠로 인식되지 않으므로, 9:16 프레임 안에 배치해 세로 파일로 내보내는 방식이 실용적이다.
- 상하 여백을 단순 검은색으로 채우는 것에 대해서는 출처마다 의견이 갈린다 → **검은색 대신 디자인 배경(블러, 단색 그라데이션, 패턴)** 으로 채우는 쪽이 안전하다.

## 3. 안전 영역 (1080×1920 기준)
플랫폼 공식 수치는 없고 도구마다 다르다. **보수적인 값을 쓴다.**

| 영역 | 비워둘 범위 (출처별 편차) | 테마 설계 기준값 (제안) |
|---|---|---|
| 하단 | 461~672px (채널명·구독 버튼·제목·음원) | **672px** |
| 오른쪽 | 173~192px (좋아요·댓글·공유 버튼) | **192px** |
| 상단 | 약 288px (검색·메뉴) | **288px** |
| 중앙 안전 영역 | 약 984×1500px | 제목·자막은 이 안에서만 |

- 자막은 **가로 중앙**에 둔다 (오른쪽 버튼을 피하려고 왼쪽으로 치우치지 않음).
- **가장 긴 두 줄 자막**으로 겹침을 테스트한다.
- 제목·강조 스티커·자막이 같은 안전 영역을 나눠 쓰므로 서로 겹치지 않게 우선순위를 정한다.

### 7.2 발견한 패턴
1. **3단 구성이 가장 흔하다 (10개 중 5개).** 배경은 검정과 흰색 두 갈래. 흰 배경은 SNS 게시물처럼 보이는 "게시물형"(프로필 헤더 + 제목 + 영상 + 질문/댓글)으로 발전해 있다.
2. **제목 공식이 매우 일정하다.** 2줄, 초굵은 고딕, 화면 상단 15~25% 지점. **1줄은 수식어(흰/검정), 2줄은 핵심(노랑)** 이거나 핵심 키워드만 빨강·파랑으로 칠한다. 문구는 숫자 리스트형("5가지", "99%가 모르는")과 질문형("~했더니?", "~갔어?")이 대부분.
3. **자막은 "흰 굵은 글씨 + 두꺼운 검정 테두리", 1~3어절 구절 단위**가 표준. 해외에서 표준이라는 단어별 색 강조(§1)는 이번 국내 표본에서는 거의 보이지 않았다. → **국내 테마는 구절 자막을 기본으로 하고, 단어 강조는 옵션**으로 둔다.
4. 자막 위치: 풀스크린은 화면 60~75% 높이 가운데, 3단은 가운데 영상의 하단 안쪽.
5. **예능 클립의 공통 장치:** 효과 텍스트(의성어·손글씨 "ㅋㅋ"), **댓글 카드**(예능 4개 중 3개), 출처 표기("출처: 채널명 EP.21"), 채널 로고·구독 스티커.
6. 정보형은 제목에 숫자를 넣고, 화면 전환이 잦은 실사 위주이며, 효과는 절제한다.

### 7.3 설계에 주는 시사점
- **MVP 테마 2종을 모두 3단 구성으로 만들면 얼굴 추적 크롭 없이도 완성도가 나온다.** 가운데에 16:9 원본을 그대로 두기 때문이다. 얼굴 추적(reframe)은 MVP에서 빼고, 풀스크린 테마를 추가할 때 넣는 것을 권장한다. (개발 범위가 크게 줄어듦)
- 블로그 입력에는 흰 배경 게시물형이 잘 맞는다. 프로필 헤더 = 블로그 이름, 가운데 = 블로그 이미지, 하단 = 요약 문장.
- **댓글 카드 주의:** 실제 없는 댓글을 AI로 만들어 진짜 댓글처럼 보이게 하는 것은 시청자를 속이는 일이므로 하지 않는다. 대안: (a) 유튜브 원본의 실제 인기 댓글을 API로 가져와 작성자 이름을 가린 채 표시, (b) 댓글 모양이 아닌 "한줄 요약" 카드로 디자인을 구분.
- 출처 표기는 유튜브 원본일 때 자동으로 넣는다 (채널명, 영상 제목). 저작권 분쟁 완화에도 도움이 된다.
- 제목 생성 프롬프트는 "2줄, 1줄 수식어 + 2줄 핵심, 숫자형 또는 질문형, 줄당 10자 안팎"으로 형식을 강제하고, 핵심 키워드 위치를 함께 출력하게 해서 색 강조에 쓴다.

## 8. 테마 2종 최종 제안 (관찰 반영)

### 테마 A — "예능 블랙" (3단, 검정 배경)
| 요소 | 규칙 (1080×1920 기준, 잠정값) |
|---|---|
| 레이아웃 | 상단 제목 영역 / 가운데 16:9 미디어(가로 1080 꽉 채움, 높이 608) / 하단 보조 영역. 미디어 세로 위치는 화면 중앙보다 약간 위 |
| 배경 | 검정 단색 (옵션: 원본 블러를 아주 어둡게) |
| 제목 | 상단 안전 영역(288px) 바로 아래, 2줄, 초굵은 고딕, 줄당 최대 10~12자. 1줄 흰색, 2줄 노랑. 또는 핵심 키워드만 빨강·파랑 |
| 자막 | 미디어 하단 안쪽, 흰 굵은 글씨 + 검정 테두리, 1~3어절. 단어 강조는 옵션(꺼짐 기본) |
| 효과 | 강조 순간 효과 텍스트(의성어/ㅋㅋ) 자동 삽입 옵션, 펀치인 줌, 점프컷 |
| 하단 영역 | 실제 댓글 카드(이름 가림) 또는 한줄 요약 카드, 출처 표기 |
| 블로그 입력 시 | 미디어 = 블로그 이미지 + 천천히 줌·패닝, 하단 = 핵심 문장 카드 |
| 어울리는 콘텐츠 | 예능, 토크, 인터뷰, 리액션 |

### 테마 B — "게시물 화이트" (3단, 흰 배경 게시물형)
| 요소 | 규칙 (잠정값) |
|---|---|
| 레이아웃 | 상단 프로필 헤더(아바타 + 이름 + @핸들) / 제목 / 가운데 16:9 미디어 / 하단 질문·요약 문구 |
| 배경 | 흰색 단색 |
| 제목 | 2줄, 검정 초굵은 고딕, 질문형·숫자형. 핵심 키워드만 포인트 색 1개 |
| 자막 | 미디어 하단 안쪽, 흰 글씨 + 검정 테두리 (블로그 입력 시 나레이션 자막) |
| 하단 문구 | 굵은 검정 질문/요약 1줄 + 출처 |
| 효과 | 절제: 부드러운 줌, 장면 사이 짧은 컷. 효과 텍스트 없음 |
| 블로그 입력 시 | **기본 테마.** 프로필 헤더 = 블로그 이름, 미디어 = 블로그 이미지 슬라이드, 나레이션 + 자막 |
| 어울리는 콘텐츠 | 정보, 꿀팁, 블로그 요약, 뉴스·상식 |

### 남은 검증
- 위 수치는 화면을 눈으로 본 근사치다. Remotion 샘플을 만들어 실제 휴대폰 쇼츠 화면(버튼 겹침 포함)에서 확인 후 확정한다.
- 정보·지식 나레이션형(얼굴 없는 영상) 표본은 이번에 확보하지 못했다(검색 페이지 로딩 실패). 블로그 테마 확정 전에 5개 정도 추가 확인이 필요하다.
- 글꼴 라이선스 확인은 여전히 남아 있다.
